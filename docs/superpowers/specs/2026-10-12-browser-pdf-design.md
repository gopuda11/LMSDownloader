# Browser-only lecture material PDF conversion

The owner requested lecture material conversion without extra installed software. A separate extension tab converts PPT/PPTX locally; it accepts observed Dankook attachment links and a local file picker fallback. No upload server, CDN runtime, native helper or extra browser permission is added. Existing video recovery stays intact.

The popup scans links in current accessible frames, recognizing .pptx/.ppt attachment names and Canvas file routes. It provides a separate material section and PDF button. Canvas attachment IDs are resolved through the logged-in /api/v1/files/:id endpoint, then downloaded from HTTPS Dankook hosts only, with a 50 MiB bounded response, timeout and HTTP/login errors. Redirect destinations are validated before body consumption. Local files follow the same limit.

Conversion runs in a sandboxed extension iframe without extension APIs or external network access (only local data/blob resource access). Packaged pinned PPTX renderer, legacy PPT renderer, html-to-image and jsPDF render up to 200 slides to image-based PDF pages, sequentially at 1.5x resolution. The parent accepts output only from its own iframe and a matching job token; only user-selected jobs run. External OOXML relationships and active embedded content are rejected; ZIP limits apply. The PDF has no searchable text. First-slide preview, progress, cancel, warning and error UI are explicit. Old binary .ppt uses the separately pinned MIT @web-ppt/core parser and image exporter; malformed/encrypted files receive an actionable error and retain original download. Complex fonts, math, charts and unsupported elements may differ from PowerPoint. Unsupported rendering events must be reported, not silently presented as perfect output.

Validation: pure policy tests (domains/routes/extensions/filename/limits), fixture PPTX with Korean text, table and shape, actual extension Chromium conversion to PDF with page count and visual checks, sandbox network test, cancellation, malformed ZIP, old PPT conversion and size error. Tests cannot establish live logged-in school document retrieval without a live attachment.
